# Changelog

All notable changes to **Ultimate Vault Sync** are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-08-24

### Added

- GitHub OAuth Device Flow authentication.
- Private per-vault repository (`obsidian-<vault-name>`).
- Auto-sync (3s debounce), pull-on-open/focus, conflict resolution UI (Keep Mine/Theirs).
- Multi-vault support, cross-platform (desktop + mobile).
- Debug logger and structured error taxonomy.
